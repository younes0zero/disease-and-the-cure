# The Disease and The Cure

**الداء والدواء** — *Al-Dā’ wa al-Dawā’* by Imām Ibn al-Qayyim al-Jawzīyah (691–751 H)

A minimal, Apple Books–style e-reader for this classic Islamic text on the diseases of the heart and their cures.

## Read online

**https://younes0zero.github.io/disease-and-the-cure/**

(Enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.)

Or open `index.html` locally in any browser.

## Features

- Page-by-page reading with keyboard, swipe, and click-zone navigation  
- Themes: Light / Sepia / Dark  
- Font size controls  
- Highlights (4 colours) + notes (saved in your browser)  
- Search, focus mode, table of contents, reading progress  

All reading data (highlights, notes, progress) stays in your browser’s local storage.
